# TripPlanner — 기능 소개

함께 만드는 실시간 여행 일정 플래너입니다. 여러 명이 동시에 같은 여행 일정을 편집하고, 숙소·식당·이동 같은 블록 단위로 일정을 구성할 수 있습니다.

---

## 1. 로그인

![로그인 화면](../img/01_login_social.png)

카카오 계정으로 간편하게 시작하거나, 이메일·비밀번호로 가입 없이 바로 로그인할 수 있습니다.

| 방법 | 설명 |
|---|---|
| 카카오 OAuth | 카카오 계정으로 1-클릭 로그인 |
| 이메일 로그인 | 이메일 + 비밀번호 직접 입력 |
| 회원가입 | 이메일·비밀번호·닉네임으로 신규 가입 |
| 비밀번호 찾기 | 가입 이메일로 인증 코드 발송 후 재설정 |

이메일 로그인 화면:

![이메일 로그인](../img/02_login_email.png)

## 2. 내 여행 목록

![여행 목록](../img/06_trip_list.png)

로그인 후 첫 화면입니다. 내가 참여한 모든 여행이 카드 형태로 표시됩니다.

각 카드에는 다음 정보가 요약됩니다.

- **목적지**와 **여행 기간** (N박 N일)
- **참여 인원 수**
- 내 **역할** — 오너 / 편집자 / 뷰어

### 새 여행 만들기

![새 여행 만들기 모달](../img/07_trip_list_create_modal.png)

우측 상단 **+ 새 여행 만들기** 버튼을 누르면 여행 제목, 목적지, 시작·종료 날짜를 입력하는 모달이 열립니다. 만들기를 누르면 바로 에디터로 이동합니다.

---

## 3. 여행 일정 에디터

![트립 에디터](../img/08_trip_editor.png)

여행의 핵심 화면입니다. 날짜별 컬럼(Day 1, Day 2 …)이 가로로 펼쳐지며, 각 컬럼에 일정 블록을 자유롭게 추가·편집·이동할 수 있습니다.

### 블록 타입

일정은 5가지 타입의 블록으로 구성합니다.

| 타입 | 색상 | 용도 |
|---|---|---|
| 숙소 | 초록 | 호텔, 숙박 시설 |
| 식당 | 주황 | 레스토랑, 음식점 |
| 카페 | 노란 | 카페, 디저트 |
| 장소 | 보라 | 관광지, 명소 |
| 이동 | 파란 | 교통, 이동 구간 |

각 블록에는 **장소명**, **시작 시간**, **소요 시간**, **비용**, **메모**를 기록할 수 있습니다.

### 실시간 동시 편집

다른 멤버가 편집 중인 블록은 이름 배지와 함께 잠금 표시됩니다(예: `지민 편집 중`). 상단에 현재 접속 중인 멤버 수와 아바타가 표시됩니다.

### 드래그 앤 드롭

블록을 드래그해 같은 Day 안에서 순서를 바꾸거나, 다른 Day 컬럼으로 이동할 수 있습니다.

### Day 관리

각 Day 컬럼 헤더에서 날짜를 직접 수정하거나, 컬럼을 삭제할 수 있습니다. 보드 오른쪽 끝 **+** 버튼으로 Day를 추가합니다.

---

## 4. 블록 추가 / 편집

![블록 추가 모달](../img/09_trip_editor_block_modal.png)

상단 툴바에서 블록 타입을 선택하거나, Day 컬럼의 **+** 버튼을 누르면 블록 추가 모달이 열립니다.

입력 필드:

- **유형** — 숙소 / 식당 / 카페 / 장소 / 이동 (탭 선택)
- **장소명** (필수)
- **시작 시간** (선택)
- **소요 시간** (분 단위, 선택)
- **비용** (원 단위, 선택)
- **메모** (선택)

기존 블록을 클릭하면 동일한 모달에서 수정할 수 있습니다. 다른 멤버가 편집 중이면 잠금 알림이 표시됩니다.

---

## 5. 멤버 관리

![멤버 관리 모달](../img/10_trip_editor_member_modal.png)

상단 **멤버** 버튼을 누르면 현재 여행에 참여한 멤버 목록을 확인할 수 있습니다.

역할은 세 가지입니다.

| 역할 | 권한 |
|---|---|
| 오너 | 전체 편집 + 멤버 권한 변경 및 제거 |
| 편집자 | 블록 추가·수정·삭제, Day 관리 |
| 뷰어 | 읽기 전용 |

오너는 편집자·뷰어의 역할을 드롭다운으로 변경하거나 멤버를 내보낼 수 있습니다.

---

## 6. 예산 관리

![예산 관리 모달](../img/11_trip_editor_budget_modal.png)

상단 **예산** 버튼을 누르면 여행의 지출 계획을 카테고리별로 기록할 수 있습니다.

카테고리: **항공 / 숙박 / 식비 / 교통 / 기타**

모달 상단에 모든 항목의 **합계 금액**이 실시간으로 표시됩니다. 항목별로 금액과 메모를 입력·수정·삭제할 수 있습니다.

---

## 7. 초대 링크

![초대 페이지](../img/12_invite.png)

에디터 상단 **공유** 버튼을 누르면 고유한 초대 링크가 클립보드에 복사됩니다.

링크를 받은 사람이 접속하면 여행 제목, 목적지, 기간, 현재 참여 인원을 미리 확인하고 **참여하기** 버튼 한 번으로 여행에 합류할 수 있습니다. 참여 즉시 에디터로 이동합니다.

---

## 화면 흐름 요약

```
로그인 (/login)
  └─ 여행 목록 (/)
       ├─ 새 여행 만들기 → 에디터로 이동
       └─ 여행 카드 클릭 → 에디터 (/trips/:tripId)
            ├─ 블록 추가·편집 모달
            ├─ 멤버 관리 모달
            ├─ 예산 관리 모달
            └─ 공유 링크 복사

초대 링크 (/invite/:shareToken)
  └─ 참여하기 → 에디터로 이동
```
